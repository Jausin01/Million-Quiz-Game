# Sounds

The game plays these files when they exist. Without them it runs silently.
Use your own audio (WAV or OGG with the same names), and only music you have the rights to.

| File | Used for |
|---|---|
| `menu_theme.wav` | Looping music on the main menu |
| `quiz_theme.wav` | Looping music during a game |
| `right_answer.wav` | Sound after a right answer |
| `game_over.wav` | Sound after a wrong answer or when time runs out |
